Conecta Google Sheets

Para guardar tus gastos y leer Gmail automáticamente, sigue estos pasos una vez:

Paso 1
Crea un Google Sheet
Ve a sheets.google.com y crea una hoja nueva llamada "Gastos Personales"
Paso 2
Abre el editor de Apps Script
En la hoja: Extensiones → Apps Script
Paso 3
Pega el código
Borra el contenido de Code.gs, pega el archivo Code.gs que te entregué y haz clic en 💾
Paso 4
Despliega como web app
Implementar → Nueva implementación → Tipo: App web → Acceso: Cualquier usuario → Implementar. Autoriza los permisos de Gmail y Sheets cuando te lo pida.
